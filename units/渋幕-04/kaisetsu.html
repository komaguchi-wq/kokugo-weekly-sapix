今井むつみ『ことばと思考』（岩波書店）

ことばが人間の認識に何をもたらすか、を赤ちゃん・熟達者・チンパンジーの例で説明する文章である。筆者の言いたいことは二つに分けて読むとよい。前半（1〜18行目）は、ことばを学ぶと、不必要な情報に注意を向けないようになる（細かい違いを区別しなくなる・必要な情報だけを処理する）。後半（19〜55行目）は、ことばに導かれて、見た目ではなく「関係の同一性」で「同じ」とみなせるようになる。この二つめの力は、動詞の学習・比喩・アナロジー（錠：鍵＝ペンキ缶：△）に共通していて、チンパンジーは教えられた範囲でしか使えないが、人間の子どもは自分から発展させていく、という締めくくりになる。

一 問一a・b・c カタカナを漢字に・漢字をひらがなに 知識問題

a カンテン＝観点。本文は「この──から言語が人間にもたらしたものを考え」なので、ものを見る立場・角度の観点。「視点」「見地」と同じ仲間で、「観」は観察の観。
b ヨダン＝余談。本文は「──だが、様々な分野で」と話をわきにそらす所なので、本筋から外れた話の余談。「余」はあまり、「談」は話。
c 絞り＝しぼり。「情報を絞り込んで取り込み」なので、範囲をせばめる意味の「しぼる」。解答らんに「り」が印刷されているので、書くのは「しぼ」の二字。
答え：a 観点　b 余談　c しぼ
今回：a 観点 ○／b 余談 ○／c しぼ ○（2点×3）。三つとも取れている。

一 問二 「エイキョウ」と同じ漢字 知識問題

「エイキョウ」＝影響。問題は「エイ」「キョウ」の順に二つ選ぶ形なので、先に自分で「影」「響」と書いてから選択肢にあたる。エイ＝影はキ「クラスの中でかげのうすい存在」、キョウ＝響はウ「言葉が心にひびいた」。ほかは別の字で、ア 郷（郷に入っては郷に従え）／イ 営（営む）／エ 強（強いる）／オ 陰（光陰矢のごとし）／カ 競（競い合う）／ク 栄（栄えある）。オ「光いん」は「陰」で、「影」と読みも意味も近いが別の字なので、ここが引っかけになる。熟語は一字ずつ訓読みに戻すと見分けがつく（熟語（塾技96））。
答え：キ・ウ
今回：キ・ウ ○（5点）。順番も指示どおりに書けている。

一 問四 一般的な考え方を挙げた理由 理由型・記号選択

👀 ① 聞き方

問いの最後は「筆者が挙げているのはなぜか」→ 読解の設計カードの理由型。やることは 1 傍線の前後の接続語を探す → 2 筆者の主張を支える理由の文を探す → 4 原因→結果の向きを確かめる → 5 向きが逆の選択肢を切る。聞かれているのは「一般的な考え方」の中身ではなく、筆者がそれを出した目的である。

📚 ② 合図を探す

  • 傍線②の直後に「知識に関してはその通りである。しかし、知覚情報の処理というのは、一度にできることが限られている」（9行目）。「一般に〜と考えられている」→「その通り」→「しかし」は、いったん認めてから自分の主張を出す形で、「しかし」の後ろが筆者の言いたいことになる（接続語の活用（塾技13））。
  • つまり一般論は比べるために置いた土台で、「原因・理由」と「結果」はペアで読む（塾技17）のとおり、理由は「しかし」の後ろ＝「知覚情報の処理には限界がある → 不必要なことに注意を向けないことが大事（16〜17行目）」にある。
  • 筆者は一般論を「間違い」とは言っていない。「知識に関してはその通り」と認めている。ここが選択肢を切る物差しになる。

🔍 ③ 理由で選択肢を切る

  1. 要素を二つ決める。要素A＝一般論（知識が増える）は認めたうえで比べている、要素B＝言いたいのは「情報処理には限界があるので不必要な情報に目を向けなくなる」こと。
  2. ウは「一般的な考え方と比較しながら」＝A、「成長するにつれて知識は増大しても、情報処理の限界があるので、不必要な情報に目を向けなくなるという事実をわかりやすく伝える」＝B。両方そろう。
  3. 切る言い方は三つ。言いすぎ・本文に書かれていない（塾技55）／内容不足・因果関係のねじれ（塾技56）／問いにきちんと答えていない（塾技57）。

ア 熟達者の情報処理をわかりやすくするため熟達者の話は「余談」（12行目）で、一般論を出した目的ではない（問いに答えていない）
イ 一般的な考え方が間違っていることを強調するため筆者は「知識に関してはその通り」と認めている。「知識の増加にも限界がある」も本文に無い（言いすぎ）

今回：ウ ○（5点）。イの「間違っていることを強調」に引かれずに済んだのは、「知識に関してはその通り」を読めていたからで、合図の読み方が正しい。

📚 ② 空欄の前後を切る

一 問六 「大学生の彼は、学者のタマゴだ。」が表すこと 説明型・記述6点

👀 ① 聞き方

問いの最後は「どのようなことを表していると理解できるか」→ 読解の設計カードの説明型。やることは 1 比喩を切る → 2 たとえ（タマゴ）を印 → 3 本文の言葉で言いかえ → 5「（だれが）（部品）＋（部品）ということ。」。6点なので部品は2個＋主語。

📚 ② 傍線を切る

  • 傍線③は「モノが違っても関係が同じことを「同じ」とみなすことは、比喩や類推でも見られる」。この問いは、傍線の直後にある本文の比喩の解き方を、別の文に当てはめる問題である。
  • 本文の手本は「書物は脳にとって、もっともよく効く肥料だ」。筆者はこれを「植物」と「脳」が「成長させるために栄養が必要」という関係で同じ（29〜30行目）と説明している。つまり、たとえているもの・たとえられているもの・共通点の三つに分ける（比喩表現（塾技29））と、共通点は「見た目」ではなく「関係」で言う、と決まる。
  • 「大学生の彼は、／学者の／タマゴだ」。たとえられているもの＝大学生の彼、たとえているもの＝タマゴ。タマゴとは「今はまだ鶏ではないが、育てば鶏になるもの」。この「今は〜ではない／やがて〜になる」の二つを、彼と学者の関係に移す。

✍️ ③ 部品を集める

  1. 部品A（だれが）：「大学生の彼は」。問いの文の主語をそのまま使う。
  2. 部品B（タマゴ＝今の状態）：まだ学者ではない → 「今は未熟だ」。
  3. 部品C（タマゴ＝これから）：育てば学者になる → 「学者を目指している」。
  4. 出力の形：「（大学生の彼は）（今は未熟だが）（学者を目指している）ということ。」 比喩の言葉「タマゴ」を残さず、別の言葉に言いかえる（──線部の説明（塾技77））。
模範解答：大学生の彼は、今は未熟だが学者を目指しているということ。
今回：6点中3点。答案は「これから立派な学者になれるいい素材の青年であること。」。
部品チェック＝A ×（「大学生の彼は」が無く「青年」で代用）／B ×（「いい素材」は見こみの話で、今はまだ未熟という今の状態が書かれていない。先生もここに青の波線と「？」）／C ○（「これから学者になれる」）。
Bは、タマゴの「まだ鶏ではない」側を訳せば出る部品で、本文の手本も「植物」と「脳」の今の状態（栄養が要る）で共通点を言っている。比喩はたとえているものを「今は／やがて」の二つに分けてから書こう。文末も「〜であること。」でなく「〜ということ。」で閉じる。

一 問七 「抽象的」の対義語 知識問題

抽象的⇔具体的。本文では「非常に抽象的な関係性」（30行目）＝目に見えない、頭の中でとらえる関係、と使われている。その反対が、目に見える・手でさわれる形のある「具体的」。「見た目の類似性（具体）／関係の同一性（抽象）」というこの文章の軸そのものなので、意味もセットで押さえる（対義語・類義語（塾技97））。漢字三字。
答え：具体的
今回：具体的 ○（2点）。

  3. 部品C（関係）：51〜52行目「関係の同一性を理解し、それに基づいて類推したり、カテゴリーをつくったりすることはとても難しい」。類推・カテゴリーまで写す。

二 問五 「旅情が身についてきた」とはどういうことか 説明型（理由つき）・記述8点

👀 ① 聞き方

問いの最後は「どういうことか。『身についてきた』理由も分かるように説明しなさい」→ 読解の設計カードの説明型。文末は「〜ということ。」。やることは 1 傍線を切る → 2 むずかしい言葉に印 → 3 本文の言葉で言いかえ → 5「（理由）で、（言いかえ）ということ。」の順。「理由も分かるように」は部品が一つ増える合図で、8点なら部品は2〜3個。

📚 ② 傍線を切る

  • 「旅情が／身についてきた」。「旅情」は抽象語で、旅先で感じるしみじみとした気分のこと。「身についてきた」は自分のものになってきた、という意味。
  • 言いかえは傍線の直後にある。27〜28行目「このままずっとこの温泉宿に泊っていたいような気持ちにもなった」。これが「旅情が身についた」の中身で、旅をしている状態を好ましく思うようになった、ということになる。
  • 理由は傍線の直前「それらの事物のおかげで」。「それら」は指示語なので、直後をヒントにして前を見る（塾技12）→ 25〜26行目「昨日のうちにわたしの出遇ったかずかずの事物——狐を飼っている男、…村の花嫁、…夕暮れの風景」。

  1. 部品A（理由）：本文25〜26行目「出遇ったかずかずの事物」。狐を飼う男・村の花嫁・夕暮れの風景は具体例なので、まとめの言葉に直す（具体例はその前後のまとめに着目（塾技16））→「思いがけない人や風景との出会い」。
  2. 部品B（旅情が身についた＝）：本文27行目「このままずっとこの温泉宿に泊っていたい」→「旅の良さを感じ取れるようになった」。
  3. 出力の形：「（旅先での思いがけない人や風景との出会いを通して）、（旅の良さを感じ取れるようになった）ということ。」解答らんは二行なので、八〜九割まで（コアを決めて要素を足す（塾技87））。
別紙も、直後の「このままずっとこの温泉宿に泊っていたいような気持ちにもなった」＝旅をしている状態を好ましく思う、直前の「それらの事物のおかげ」＝理由、の二か所で組んでいる。傍線の直前と直後だけで部品がそろう問題である。
模範解答：（旅先での）思いがけない人や風景との出会いを通して、旅の良さを感じ取れるようになったということ。
今回：8点中3点。答案は「今まで娘とけんかして気分を悪くしていたが、初めての一人旅で色々な経験をして、旅に対する感性が目芽え、安定したということ。」。
部品チェック＝部品A 半分（「色々な経験をして」で理由の位置には触れているが、「思いがけない人や風景との出会い」という中身が無い）／部品B 半分（「旅に対する感性が芽生え」は近いが、「旅の良さ」「このまま泊まっていたい」という向きが無く、「安定した」は本文に無い）。
先生の青ペンは「けんかして気分を悪くしていた」のあたりに波線と「？」、「目芽え」に「芽生え」。「娘とけんかして気分を悪くしていた」は本文に無く、本文は24行目「忘れたいと思って旅にまで出てきた」である。部品を拾えなかった＝傍線の直前「それら」の中身と直後の一文を写さず、自分の言葉で話を作った。次は、傍線の直前と直後の一文に線を引いて、その言葉だけで組もう。

二 問六 娘が「顔をまっ赤に」したのはなぜか 理由型・記述12点

👀 ① 聞き方

問いの最後は「したのはなぜか。理由を説明しなさい」→ 読解の設計カードの理由型。文末は「〜から。」。物語なので、やることは 1 傍線の前後の合図 → 2 きっかけの出来事 → 4 原因→結果の向き → 6「（きっかけの出来事）で、（気持ち）になったから。」の順。12点なので部品は3〜4個。

📚 ② 合図を探す

  • 合図は傍線の直前の一文にある。52行目「娘はそう何気なくいってしまってから、急にその自分のいった言葉にはッと気がついたように見えたが」。きっかけ＝自分の言った言葉、と決まる。
  • その言葉は51行目「毎晩十二時過ぎまでお勉強なさっていらっしゃいましたが」。「わたし」にSのことを聞かれて答えたセリフである。
  • なぜその言葉が恥ずかしいのか。Sの毎晩の行動まで知っている＝Sの動向にずっと注意を払っていた＝Sに特別な関心を寄せていた、と自分で明かしてしまったから。裏づけは57行目、「わたし」がSを「羨望する」と言うところと、40行目のSの「いいにくい事情」。原因と気持ちはセットでつかむ（塾技22）。
  • 「顔をまっ赤に」は気持ちを直接書かない言い方なので、間接的な表現は心情語に直す（塾技85）→ はずかしさ。

✍️ ③ 原因→結果の向きを確かめる

  1. 部品A（きっかけ）：本文51行目「毎晩十二時過ぎまでお勉強なさって」→「『わたし』にSについて問われ、毎晩遅くまでの行動を気にかけていたとわかる発言をしてしまった」。
  2. 部品B（その言葉の意味）：本文57行目「羨望する」が裏づけ →「Sに特別な関心を寄せていたと気づかれてしまったと思った」。
  3. 部品C（気持ち）：顔をまっ赤に →「はずかしくなった」。
  4. 出力の形：「（Sについて問われた際、Sの行動を気にかけていたとわかる発言をしてしまい）、（特別な関心を寄せていたと気づかれたと思って）、（はずかしくなった）から。」向きを確かめる——発言→気づかれた→はずかしい→顔が赤い、で傍線につながる（理由が傍線とつながるか確認し、文末は「〜から」（塾技76））。
別紙も同じ順で、「自分の言ったことばに気づいたとき」→「毎晩十二時過ぎまで勉強していたという内容」→「Sの動向に相当な注意を払っていた」→「羨望する」から娘がSを異性として意識していたと分かる→「うっかり主人公に話してしまったので、はずかしさで顔を赤らめている」と説明している。
模範解答：「わたし」にSについて問われた際、毎晩遅くまで行動を気にかけていたことがわかる発言をしてしまい、Sに特別な関心を寄せていたと気づかれてしまったと思って、はずかしくなったから。
今回：12点中4点。答案は「S本人に彼との付き合いは言わないようにと言われていたのに、会話の流れで言ってしまい、はずかしく、友達と心を気づかってあげるSの気持ちを大無しにして申し訳ない気持。」。
部品チェック＝部品A 半分（「会話の流れで言ってしまい」はあるが、何を言ったか＝51行目のセリフが無い）／部品B ×（「Sに口止めされていた」は本文に無い。先生もこの部分に波線を引いている）／部品C ○（「はずかしく」）。ただし文末が「申し訳ない気持。」で、理由型なのに「〜から。」になっていない＝聞かれたことに答えていない形で終わっている。先生の青ペンはもう一つ、「大無し」→「台無し」。
部品を拾えなかった＝傍線の直前の一文（52行目）を使わず、Sと娘の話を自分で作った。次は、傍線の直前の一文に線を引き、その中の「その自分のいった言葉」が本文のどのセリフかを指でさしてから書こう。文末の「から。」は先に書いておく。

二 問七 空らんAに入る熟語 空欄型・記号選択

👀 ① 聞き方

問いの最後は「Aに入る熟語を選びなさい」→ 読解の設計カードの空欄型。やることは 1 空欄の前後の言葉を見る → 3 入れて読み返す。熟語の意味を先に思い出してから当てはめる。

📚 ② 空欄の前後を切る

  • 空欄を含む一文は「わたしの／　A　／は一掃された」。直前は46行目「別にSのことを迷惑がりもしていないらしい様子だった」。空欄の前後にヒントがある（塾技70）——「一掃された」＝きれいに消えた、なので、Aには消えてよかったもの＝心配が入ると決まる。
  • 心配の中身は39行目「Sがこの宿屋にどんな不義理をしていようと」。Sが宿に迷惑をかけていたかもしれない、と「わたし」は思っていた。それが娘の様子で消えた。
  • 熟語の意味：逆鱗＝目上の人の激しい怒り／蛇足＝よけいな付け足し／白眉＝いちばん優れたもの／矛盾＝つじつまが合わないこと／杞憂＝しなくてもよい心配、取り越し苦労。

🔍 ③ 入れて読み返す

  1. 「わたしの杞憂は一掃された」＝いらない心配が消えた。前の一文とそのままつながる。
  2. 残りは入れて読み返すと日本語にならない。「わたしの逆鱗は一掃された」「わたしの蛇足は一掃された」のどれも、前の文の「迷惑がりもしていない」と結びつかない。
答え：オ
今回：オ ○（4点）。「一掃された」から前を見て、心配の話だと決められている。

二 問八 中島敦の作品 知識問題（文学史）

中島敦＝『山月記』。詩人になれなかった男・李徴が虎に変わる話で、堀辰雄と同じ昭和の初めに活躍した。ほかの選択肢は作者がすべて別で、『小僧の神様』＝志賀直哉、『蜘蛛の糸』＝芥川龍之介、『山椒魚』＝井伏鱒二、『檸檬』＝梶井基次郎。渋幕は本文の作者と同時代の作家・作品を聞く形をくり返すので、作者と代表作は組で覚える。
答え：エ
今回：オ ×（5点）。『檸檬』は梶井基次郎。中島敦＝山月記（虎になる話）、梶井基次郎＝檸檬（果物屋のレモン）、と題名の中身ごと結びつけて覚え直そう。

  • 記号は問三・問七が○で、本文の前後から理由や心配の中身を決める読み方はできている。問四は二つのうちウは取れていて、落としたのはオの後半を本文と照らさなかった一点。二つ選ぶ問題は五つ全部に○×を付けてから残す。
