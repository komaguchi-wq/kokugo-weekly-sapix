「子どもは守られる存在」「子どもは将来のために力を身につける」という、だれもが当然と思っている二つの考えに、筆者が順に「錯覚」だと言っていく文章である。前半（1〜37行目）は〈守る―守られる〉の話。人は守られつつ同時に守る、他者の役に立って喜ぶのが人間の自然なのに、おとなが善意で〈ひたすら守る〉と、その自然を子どもから奪ってしまう。後半（38〜90行目）は力と生活の話。身につけた力は本来、たったいまの生活のなかで使って世界を広げるものなのに、学校の力は「将来」のためと位置づけられて試験にしか使われず、使われない力は剥がれ落ちる。これが「空しい学び」である。

一 問四 「一つの自然」と表現しているのはなぜか 理由型・記号選択

👀 ① 聞き方

問いの最後は「『一つの』と表現しているのはなぜか」→ 読解の設計カードの理由型。ただし聞かれているのは出来事の理由ではなく、「一つの」という言葉を選んだ理由である。やることは 1 傍線の前後で合図を探す → 2 筆者がこの言葉を使った理由の文を探す → 5 向きが逆の選択肢を切る、の順。

📚 ② 合図を探す

  • 「一つの」は数を示す言葉で、「一つだけ」ではなく「いくつかあるうちの一つ」という含みを持つ（数を示す言葉（塾技15））。だから探すのは、ほかにも「人間の自然」と呼ばれているものが本文にあるかである。
  • 見つかる。9〜10行目「人は守られつつ、同時に守る…いわば人間の自然である」、15行目「〈守る―守られる〉という人間の自然」、そして18行目「これもまた人間の自然であって」（他者が喜んでくれると嬉しい）。「も」「また」は同じ仲間がほかにもある合図（助詞「〜は」「〜も」「〜や」（塾技14））。別紙も18行目の「また」を根拠にしている。
  • つまり筆者は「人間の自然」を複数挙げるつもりで書いていて、傍線①はその最初の一つ。「一番重要」「一つ目に訪れる」とは一度も言っていない。

🔍 ③ 理由で選択肢を切る

  1. 選択肢を見る前に理由を決めておく。「人間の自然」はほかにもあるから、この一つである。
  2. 選択肢を前半／後半に切って本文と照らす。「一つだけ」「一番重要」「他の生き物と異なる」「一つ目に訪れる」は、どれも本文に無い限定を足している（言いすぎ・本文に書かれていない（塾技55））。
選択肢切り方
ア 予定されている自然は一つだけ18行目「これもまた人間の自然」と正反対（向きが逆）
イ 一番重要な自然重要さの順位は本文に無い（本文に書かれていない）
ウ 他の生き物と異なっている「ほかの生き物にあまり例がない」（18行目）は喜びの話で、「一つの」の理由ではない（問いに答えていない）
エ 一つ目に訪れる予定の自然順番の話は本文に無い（本文に書かれていない）
オ 他にも自然だと言えることがある10行目・18行目の「人間の自然」と合う → 正解

なお別紙は18行目の「また」という正解の根拠だけを示している。ア〜エを切った上の理由は、私が本文と照らして決めたものである。

答え：オ
今回：オ ○（5点）。「一つの」を「ほかにもある」と読めている。

一 問五 「奇妙な生き物」のどこが奇妙か 説明型・記号選択

👀 ① 聞き方

問いの最後は「どのようなところが奇妙なのか」→ 読解の設計カードの説明型。やることは 1 傍線を切る → 2 使えない言葉（奇妙）に印 → 3 本文の言葉で言いかえ → 記号なので、その部品で選択肢を切る、の順。

📚 ② 傍線を切る

  • 「奇妙な／生き物である」。「奇妙」が評価語で、何が奇妙なのかは傍線の中に無い。傍線の説明は、たとえや評価語を本文の言葉に置きかえる（──線部の説明（塾技77））。
  • 置きかえは傍線の直後にある。16〜17行目「自分の力を使って自分の利益になることを行い、それがうまくいけば嬉しいというのは、個体が生き残っていくために当然のことだが」→ ここは奇妙ではない。続く17〜18行目「自分の力を使って何かをやって、他者、とりわけ身近な他者が喜んでくれると、それがまた嬉しい。…ほかの生き物にはあまり例がない」→ ここが奇妙。別紙もこの「当然のこと」と「嬉しい」の切り分けで説明している。
  • 「当然のことだが」のあとに本題が来る形なので、「だが」の後ろが奇妙の中身だと決めてよい（接続語の活用（塾技13））。

🔍 ③ 部品で選択肢を切る

  1. 部品は二つ。①自分の利益にならなくても（自分のためなら当然だから）、②他者が喜ぶと自分も嬉しい。この二つが入った選択肢を探す。
  2. 選択肢を前半／後半に切って部分ごとに照らす（選択肢の部分チェック（塾技52））。アは「自分のためになることを行う…嬉しい」で、本文が「当然」と言った側を奇妙だとしている。ここで切れる。

イ 守られる機会は増え、喜ばせる機会は減っている22〜23行目の内容だが、それは今の社会の話で「生き物として奇妙」の説明ではない（問いに答えていない）

今回：ウ ○（5点）。「当然」と言われた側（ア）を切って、「だが」の後ろで選べている。

一 問六 「善意に基づくある種の錯覚に…気づいているだろうか」で筆者が言いたいこと 説明型・記号選択

👀 ① 聞き方

問いの最後は「ここで筆者は何を言いたいのか」→ 読解の設計カードの説明型。傍線が長いので、1 傍線を「／」で切る → 2 「善意」「錯覚」「気づいているだろうか」を本文の言葉に直す → 3 その部品で選択肢を切る、の順。傍線の前の一文ではなく、傍線そのものを言いかえる問題である。

📚 ② 傍線を切る

  • 「子どもに対する／この善意に基づく／ある種の錯覚に／私たちはどこまで気づいているだろうか」。三つの言葉を本文で決める（──線部の説明（塾技77））。別紙も「分けて考えましょう」と、この切り方から入っている。
  • 善意＝35行目「おとなたちが善意で子どもたちを〈ひたすら守る〉」。錯覚＝守ることが子どものためになるという思いこみ。実際は36行目「子どもたちから、相手に役立ち、相手を喜ばせて喜ぶという人間の自然を奪う」ので、ためになっていない。
  • どこまで気づいているだろうか＝疑問の形だが、34行目「子どもは〈ひたすら守られる存在〉にされてきた」と、守りすぎが現に続いている。つまり筆者の答えは「気づいていない」である。別紙も「気づいていないと筆者は考えている」と、この一点を根拠に挙げている。

🔍 ③ 部品で選択肢を切る

  1. 部品は三つ。①守ることは良いことだと信じている（善意）、②守りすぎは子どものためにならない（錯覚）、③おとなはそれに気づいていない（気づいているだろうか）。
  2. 選択肢を前半／後半に切る。イは「守りすぎは喜びを奪う」で②だけ。③の「気づいていない」が無い。これは傍線の前の一文（36行目）の言いかえであって、傍線そのものの言いかえではない（内容不足（塾技56））。
  3. エは「子どものためになる行いだと信じていて」＝①、「過度に守る弊害」＝②、「多くの大人たちは理解していない」＝③。三つそろうのでエに決まる。
選択肢切り方
ア 守る必要があるという認識は錯覚／突き放した方がよい35行目「『子どもを守れ』というのは当然のことである」と逆。錯覚なのは「守りすぎ」であって「守ること」ではない（言いすぎ）
イ 守りすぎは喜びを奪う②だけで③が無い。傍線の前の一文の言いかえ（内容不足）

エ ためになると信じていて／弊害を理解していない①②③がそろう → 正解

なお別紙は、傍線を分けて考え、「気づいていない」という筆者の考えを正解の根拠として示している。ア・ウ・オを切った上の理由は、私が本文と照らして決めたものである。

答え：エ
今回：イ ×（5点）。イは36行目の言いかえとして正しく、本文と照らすと切れない。切れたのは傍線の最後のパーツ「気づいているだろうか」で、イにはそれが無い。部品を拾えなかった失点＝傍線を最後まで切らず、前の一文で選んだ形である。次は、傍線の中の言葉を全部「／」で切って、最後のパーツまで選択肢にあるかを見る。

一 問七 「文字の読み書きなども、また同じである」のはどのような点か 説明型・記述8点（50字以内）

👀 ① 聞き方

問いの最後は「どのような点で『同じである』のか。五十字以内で説明しなさい」→ 読解の設計カードの説明型。文末は問いの名詞に合わせて「〜点。」。やることは 1 傍線を切る → 2 「同じ」の指す中身を前から取る → 3 本文の言葉で部品を集める → 5「（部品）＋（部品）点。」の順。部品の数は8点÷3〜4＝2〜3個。

📚 ② 傍線を切る

  • 「文字の読み書きなども／また同じである」。「なども」「また」は、前に出た仲間と同じだという合図（助詞「〜は」「〜も」「〜や」（塾技14））。「同じ」は指示語のはたらきをしていて、中身は前にある（指示語は直後をヒントにして前を見る（塾技12））。
  • 前の仲間は「歩く力」（51〜53行目）と「ことばの力」（53〜54行目）。どちらも具体例なので、答えは例そのものではなく、例のあとのまとめから取る（「具体例」と「まとめ」（塾技16））。まとめは55行目「力を身につけるということは、そこにその力を使って生きる新たな世界が広がるということにほかならない」。
  • もう一つ前にも決まりの文がある。49〜50行目「身につけた力は、本来、たったいま生きている自らの生活世界のなかで使うものであって、将来のために貯めておくものではない」。「同じ」の中身はこの二文でそろう。別紙も「傍線④の前の部分」と、文字の例のあとの「まとめ」（67行目「生活世界に組み込むことで、世界の広がりを味わう」）が同じ内容だ、と説明している。

✍️ ③ 部品を集める

  1. 部品A（何を）: 本文49行目「身につけた力」→ 新しく身につけた力を。
  2. 部品B（どうする）: 本文49〜50行目「たったいま生きている自らの生活世界のなかで使う」→ 現在の生活世界のなかで使うことで。
  3. 部品C（どうなる）: 本文55行目「その力を使って生きる新たな世界が広がる」→ 新しい世界が広がる。
  4. 出力の形: 「（身につけた力を）（いまの生活世界のなかで使うことで）（新しい世界が広がる）点。」50字以内なので、三つの部品だけで組み、修飾を足さない（字数指定はコアを決めてから要素を足す（塾技87））。

迷いやすいのは、文字の例の中の「とてつもなく嬉しい体験」（64〜65行目）を入れたくなるところである。嬉しさは世界が広がった結果で、問われている「同じ点」の中心はいまの生活で使う→世界が広がるのほう。50字ではそちらを優先する。

模範解答：新しく身につけた力を現在自分が生きている生活世界のなかで使うことで、新しい世界が広がる点。（四十五字）
今回：8点中3点。答案は「自分で新たな力を身につけて発達することで、今目の前にある世界に対する見方が変わり、嬉しさを感じる。」
部品チェック＝A ○（「新たな力を身につけて」）／B ×（「生活世界のなかで使う」が無い）／C ×（「世界に対する見方が変わり」は、見方の話になっていて「世界が広がる」ではない）。Bは49〜50行目、Cは55行目の、どちらも傍線より前のまとめの文にあった。文末も「嬉しさを感じる。」で終わっていて「〜点。」になっていない。部品を拾えなかった失点で、次は「なども」「また」を見た時点で、傍線より前の「〜ということにほかならない」の文を探しにいく。

一 問八 「将来」にXを合わせた 空欄型・記号選択

👀 ① 聞き方

二 問五 「引返えすのはなお慊だし、如何してくれよう」の心情 気持ち型・記号選択

今回：ア ×（5点）。部品を拾えなかった＝傍線の後半「如何してくれよう」（迷い）を要素にせず、前半の「引き返すのは嫌」だけでアを選んでいる。アの後半「決意している」は、突っ立って動けない本文と向きが逆で、ここで切れた。冊子にはアに×、ウに丸の跡があるが、用紙の答えはアになっている。次は、傍線が「〜だし、〜」のように二つの部分でできていたら、後半も要素にしてから選択肢の心情語を見比べよう。

二 問六 「コロンブスは佳く出来ていたね」と言うようになった理由 理由型（範囲指定）・記述10点

👀 ① 聞き方

問いの最後は「このようなことを言うようになったのはなぜか。その理由を【　】の範囲で説明しなさい」→ 読解の設計カードの理由型。やることは 2 物語はきっかけの出来事を探す → 4 原因→結果の向きを確かめる → 6「（きっかけの出来事）で、（気持ち）になったから。」の順。条件の言葉「【　】の範囲で」は、探す範囲の指定＝四十八行目「おやおや」から六十九行目「何にも書けない。」までだけで組む。10点なので部品は3〜4個、解答らんは三行。

📚 ② 合図を探す

  • 傍線④は、志村の画を素直にほめて「驚いちゃッた」と言っている。範囲のはじめ（四十八行目）では志村は「忌ま忌ましい奴」だったので、聞かれているのは憎む気持ちが消えて、ほめる気持ちに変わるまでに何があったかである。「なぜか」の答えは出来事の積み重ねになる。
  • 物語の理由はきっかけの出来事→気持ち→行動の順に探す（塾技22）。範囲の中で気持ちが書かれている文に線を引くと、三か所ある。五十二〜五十三行目「いまいましい奴など思う心は消えて書く方に全く心を奪られてしまった」、五十四〜五十五行目「彼が微笑するごとに、自分も我知らず微笑せざるを得なかった」、六十四行目「かえって彼が可愛くなって来た」。

✍️ ③ 原因→結果の向きを確かめる

  1. 部品A（出来事1→気持ち1）: 本文五十二〜五十三行目「志村その人の写生に取りかかった…いまいましい奴など思う心は消えて」→「志村自身を写生するうちに、わだかまりが消えていき」。
  2. 部品B（出来事2）: 本文五十六〜五十七行目「柔和な顔をし、にっこりと笑った」／六十三行目「書き給え」→「自分に対して穏やかに接してくる彼」。
  3. 部品C（気持ち2）: 本文六十四行目「かえって彼が可愛くなって来た」→「彼への好感度が高まった」。
  4. 部品D（結果＝傍線とのつながり）: だから志村の能力を「素直に認めることができた」。見つけた理由が傍線とつながるかを確かめ、文末は「〜から。」（原因・理由の説明（塾技76））。
  5. 出力の形: 「（志村を写生するうちにわだかまりが消え）、（穏やかに接してくる彼への好感が高まったこと）で、（その能力を素直に認められた）から。」。三行の解答らんは八〜九割まで使う。余りすぎは部品が足りないサイン（塾技87）。
別紙は、志村に先を越され水車の写生をあきらめた「自分」が志村自身を写してやろうと考え、いざ画板に向かうと彼へのわだかまりが消えてしまったこと、さらにその後の会話を通じて「彼が可愛くなって来た」と感じるに至り、志村のたたずまいや画作の才能にすっかり魅せられていることを、順に根拠として挙げている。部品A〜Cはここに対応する。
模範解答：志村自身を写生するうちに、わだかまりが消えていき、さらに自分に対して穏やかに接してくる彼への好感度が高まったことで、その能力を素直に認めることができたから。
