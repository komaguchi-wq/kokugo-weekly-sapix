KY-174 筆順・画数 1（p.174・15問）

p.174 このページの見方 筆順・画数 1 15問

漢字を一画ずつ書き足していく図で筆順を確かめ、最後に総画数を答えるページ。図は上から下へ一画ずつ増えていき、横の「5」「10」は五画目・十画目の目盛りになっている。いちばん下の赤字が総画数で、図の段の数と同じになる。下のカードでは、画を「横」「縦」「左はらい」「右はらい」「点」「かぎ（横に書いてから折れて下へ進む画）」「はね」という名前で、書く順にならべた。折れやはねがあっても、ひと続きで書く所は一画と数える。「右」と「左」、「友」と「有」のように、形が似ていても書き出しがちがう字を見くらべるとよい。

1 右 知識問題

左はらい → 横 → 口（縦 → かぎ → 下の横）の順。左はらいが一画目で、横から書き始める「左」とは書き出しが反対になる。
答え：五画

2 左 知識問題

横 → 左はらい → 工（横 → 縦 → 下の横）の順。横が一画目で、左はらいから書き始める「右」とは書き出しが反対になる。
答え：五画

3 王 知識問題

上の横 → 縦 → まん中の横 → 下の横の順。縦は二画目に書く。横を三本ならべてから縦を通す順ではない。
答え：四画

4 任 知識問題

にんべん（左はらい → 縦）のあと、右側は 短い左はらい → 長い横 → 縦 → 下の横。右側の一画目は横ではなく左はらいで、右上から左下へ書く。
答え：六画

5 弓 知識問題

かぎ → その下の横 → 最後の長い一画の順。三画目は、短い縦 → 横 → 折れて下へ → はね をひと続きで書く。折れる所で画を分けないので、全部で三画になる。
答え：三画

6 以 知識問題

左の縦 → 右上へのはね上げ → 点 → 左はらい → 右下へおろす長い点の順。左がわは縦とはね上げを分けて二画で書く。ひと続きにすると四画になってしまう。
答え：五画

7 書 知識問題

上は かぎ → 左右につき出る長い横 → その下に横を三本 → 上からつらぬく縦。下は 日（縦 → かぎ → 中の横 → 下の横）。縦は六画目で、上の横をすべて書いてから通す。
答え：十画

8 車 知識問題

上の横 → 日の形（縦 → かぎ → 中の横 → 下の横）→ 長い横 → 上から下までつらぬく縦の順。つらぬく縦は最後の七画目で、先に書かない。
答え：七画

9 長 知識問題

縦 → 横 → 横 → 横 → 長い横 → 縦から右上へはねる画 → 短い左はらい → 右はらいの順。一画目は左上の縦で、いちばん上の横から書き始めない。
答え：八画

10 馬 知識問題

左の縦 → 上の横 → まん中の縦 → 横 → 横 → 横から折れて下へはねる長い画 → 点を左から四つ。一画目は左の縦で、三画目にまん中の縦を書いてから残りの横へ進む。
答え：十画

11 方 知識問題

点 → 横 → かぎに折れてはねる画 → 左はらいの順。左はらいが最後の四画目になる。三画目のはねる画と順番を入れかえやすい。
答え：四画

12 糸 知識問題

「く」の形 → もう一つの「く」の形 → 点 → まん中の縦 → 左の点 → 右の点の順。下の部分は縦が先で、左右の点はそのあとに左から書く。
答え：六画

13 友 知識問題

横 → 左はらい → フの形 → 右はらいの順。横が一画目で、書き出しは「左」と同じ。左はらいから書き始める「右」「有」と区別する。
答え：四画

14 有 知識問題

左はらい → 横 → 月（縦 → かぎ → 横 → 横）の順。左はらいが一画目で、書き出しは「右」と同じ。横から書き始める「友」「左」とは反対になる。
答え：六画

15 級 知識問題

糸へんは「糸」と同じ順（く → く → 点 → 縦 → 左の点 → 右の点）。右側は 左はらい → 横から二回折れて左下へはらう画 → 右はらい。右側は三画で、折れる所をひと続きに書く。
答え：九画
