KY-175 筆順・画数 2（p.175・15問）

p.175 このページの見方 筆順・画数 2 15問

p.174 の続きで、漢字を一画ずつ書き足していく図で筆順を確かめ、最後に総画数を答えるページ。図は上から下へ一画ずつ増えていき、横の「5」「10」は五画目・十画目の目盛りになっている。いちばん下の赤字が総画数で、図の段の数と同じになる。下のカードでは、画を「横」「縦」「左はらい」「右はらい」「点」「かぎ（横に書いてから折れて下へ進む画）」「はね」という名前で、書く順にならべた。折れやはねがあっても、ひと続きで書く所は一画と数える。「世」「帯」「善」のように横を何本も書く字は、縦をどこで入れるかを図で確かめるとよい。

16 片 知識問題

左はらい → 右上の短い縦 → 横 → 横から折れて下へ進む画の順。最後の画は横と縦をひと続きに書くので、横と縦に分けて五画と数えない。
答え：四画

17 皮 知識問題

左はらい → 横から左下へはねる画 → 縦 → フの形（横 → 左はらい）→ 右はらいの順。縦は三画目で、上の横を書いてから上からおろす。下の部分は右はらいが最後になる。
答え：五画

18 世 知識問題

横 → 縦 → 縦 → 二本の縦をつなぐ短い横 → 左の縦から折れて下の横の順。左の長い縦は最後で、下の横とひと続きに書く。ここを二画に分けると六画になってしまう。
答え：五画

19 帯 知識問題

横 → 縦三本（左 → 中 → 右）→ 下の横 → 左の短い縦 → 横から折れてはねる画 → 巾の左の縦 → かぎ → つらぬく縦。つらぬく縦は最後の十画目で、先に書かない。
答え：十画

20 善 知識問題

点 → 左はらい → 横 → 横 → 横 → 縦 → 点 → 左はらい → 長い横 → 口（縦 → かぎ → 下の横）。縦は六画目で、上の横を三本書いてから入れる。そのあとの点と左はらいを、上の点と左はらいとまちがえない。
答え：十二画

21 様 知識問題

木へん（横 → 縦 → 左はらい → 点）→ 点 → 左はらい → 横を三本 → 縦はね → 左の点 → 右上へのはね上げ → 右上の短い左はらい → 右はらい。木へんの最後は点で、右はらいにしない。
答え：十四画

22 成 知識問題

左はらい → 横 → 横から折れて下へはねる画 → 右下へのびてはねる長い画 → 左はらい → 点の順。右上の点は最後の六画目で、はじめに書かない。
答え：六画

23 印 知識問題

短い左はらい → 縦 → 中の横 → 下の横 → かぎ（横から折れて下へはねる）→ 縦の順。左がわは四画で、縦と下の横を分けて書く。ひと続きにすると五画になってしまう。
答え：六画

24 発 知識問題

フの形（横 → 左はらい）→ 左の点 → 右上の短い左はらい → 右はらい → 右の点 → 短い横 → 長い横 → 左はらい → 縦から折れて右へ進みはねる画。上の部分を五画で書いてから、下の部分へ進む。
答え：九画

25 飛 知識問題

横から折れてそり、はねる画 → 点 → 点 → 縦 → 短い左はらい → 長い左はらい → 左から横に入り折れてそり、はねる画 → 点 → 点。縦は四画目で、右上の部分を書き終えてから通す。
答え：九画

26 氷 知識問題

縦はね → 左上の点 → フの形（横 → 左はらい）→ 右上の左はらい → 右はらいの順。点は二画目で、まん中の縦はねのすぐあとに書く。点をのぞくと「水」と同じ順になる。
答え：五画

27 必 知識問題

上の点 → 長い左はらい → 左上から下へ曲がってはねる画 → 左の点 → 右の点の順。左はらいが二画目で、曲がる画より先に書く。「心」の形から書き始める順ではない。
答え：五画

28 臣 知識問題

左の縦 → 上の横 → 短い縦 → 横から折れて下へ進む画 → 中の横 → 短い縦 → 下の横の順。一画目は左の縦で、まん中の短い縦は三画目と六画目に一本ずつ書く。
答え：七画

29 医 知識問題

上の横 → 矢（短い左はらい → 横 → 横 → 左はらい → 右はらい）→ 左の縦から折れて下の横。左の縦と下の横は最後に、ひと続きで書く。囲みを先に書いてから中を書く順ではない。
答え：七画

30 落 知識問題

くさかんむり（横 → 縦 → 縦）→ さんずい（点 → 点 → はね上げ）→ 右の部分（短い左はらい → フの形 → 右はらい）→ 口（縦 → かぎ → 下の横）。上から順に部分ごと書いていく。
答え：十二画
