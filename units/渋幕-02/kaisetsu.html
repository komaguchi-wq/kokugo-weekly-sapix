一 問一a・b・c カタカナを漢字に直す 知識問題

a カンショウ＝鑑賞。本文は「名画の──」なので、絵・音楽・文学など芸術を味わうときの鑑賞。同じ音の「観賞」は、花や紅葉や熱帯魚のように目で見て楽しむときに使う。「鑑」は鑑定・鑑別の鑑で、値打ちを見分ける字、と結びつけておくとよい。
b レキゼン＝歴然。はっきりしていてまぎれもない、という意味。「歴然とした差」の形でよく出る。
c コウケツ＝高潔。本文は「──さと優しさの高まり」なので、心が気高くけがれのないこと。「潔」は「いさぎよい」。「高血」という熟語は無いので、書いたあとに読み返せば気づける。
答え：a 鑑賞　b 歴然　c 高潔
今回：a「観賞」×／b 歴然 ○／c「高血」×（2点×3）。aは「名画＝目で見るもの」と考えて観賞にしたのだと思う。目で見るかどうかではなく、芸術作品なら鑑賞と覚え直そう。cは音だけで字を当てた形で、書いたあとに「高血という言葉はあるか」と一度問い直せば防げた。

一 問二A・B 空欄に入る慣用句 空欄補充・慣用句

👀 まず見るところ

空欄そのものではなく、空欄とくっついている言葉を見る。Aは「たちまち　A　か、あるいは反目するかになってしまい」。「──か、あるいは──か」は二つを並べる形なので、Aには「反目する」と逆向きの言葉が入ると決まる。Bは「作者の興奮した顔つきだけが見え、　B　のを感ずる」。興奮した顔がこちらに向いている場面なので、その顔からこちらへ飛んでくるものを考える。

📚 前提知識

  • 塾技70「キーワードの空欄補充問題」：空欄の前後にヒントがある。空欄だけをにらんでも決まらない。
  • 塾技98「ことわざ・慣用句」：肩を組む＝仲間になる・味方どうしになる／腕をこまねく＝手出しをせずに見ている／手を切る＝縁を切る／顔を見合わせる＝とまどって互いの顔を見る。

🔍 こう読み解く

  1. A：「反目する」の逆向きは「仲よくする」。四つのうちそれに当たるのはア「肩を組む」だけである。ウ「手を切る」は反目と同じ向きなので、二つを並べる形にならない。
  2. 念のため三行あとを見ると「このようなうすっぺらな共感、偏見にみちた反目は」とある。共感⇔反目とはっきり書いてあるので、共感＝肩を組む、と確かめられる。ここまで確かめれば迷いは消える。
  3. B：直前の段落に、作者がモラルを「吐きちらしてしまう」とある。吐くというつながりで、こちらに飛んでくるのはつば。ウ「生つばがとんでくる」。
  4. ア「脂汗」は自分が苦しいときのもの、イ「熱涙」とエ「血潮」は感動している側の言葉で、作者を批判しているこの場面には合わない。
答え：A ア　B ウ
今回：A ウ ×／B ウ ○（3点×2）。Aは「手を切る」を選んだ形で、「か、あるいは」で並ぶ二つは逆向きという入口を飛ばしてしまった。慣用句の意味は分かっているので、次は空欄の前後を声に出して読み、並んでいる相手を先に決めよう。Bは「吐きちらす」とのつながりで取れている。

一 問四 感想の強要に否定的な理由 理由・記号選択

👀 まず見るところ

──部①の「感想を強要することは、実は残酷な作業をしている」と、二〜三行目の「感想の強要ほど読書意欲を減退させるものはありません」は、ほとんど同じことを言っている。同じ内容が二度出てきたら、そのあいだにはさまれた部分が理由である。ここが入口で、理由を探して本文じゅうをさまよう必要はない。

📚 前提知識

  • 塾技17「『原因・理由』と『結果』」：くり返された二か所を見つけたら、その間を読む。
  • はさまれた部分に書いてあるのは二つ。①本物の感動は「ものがいえない」ものだということ。②その心の中に踏みこんで感動をあかせと迫られると、心はむなしくなるということ。
  • 塾技56「誤り選択肢のパターン② 内容不足・因果関係のねじれ」：選択肢は、この二つが両方入っているかで見る。

🔍 こう読み解く

  1. エを本文と重ねる。「言葉では表現しづらい」＝ものがいえない。「言語化することを他人に強制」＝感動をあかせと迫る。「味気ないものになってしまう」＝心がむなしくなる。三つとも本文にあるので、これが答えになる。
  2. 迷いやすいのはイである。「感動の蓄積が子どもの心を豊かにする」は、まさに筆者の主張なので正しく見える。ただしまん中の「本の拒絶につながり」は本文のどこにも書かれていない。一か所でも本文に無ければ切る、が選択肢の鉄則である。
  3. 残りも同じやり方で落ちる。
選択肢切り方
ア 嫌いな読書の苦痛から逃れるため本文で子どもが逃れたいのは「（強要という）その痛手」。逃げる相手が入れかわっている（因果ねじれ）
イ 感想の強要は本の拒絶につながり前半・後半は本文どおりだが、まん中の「本の拒絶」が本文に無い（本文外）
ウ 読むべき本を指定されたらこれは課題図書の話で、感想の強要の理由になっていない（問いに答えていない）
エ 言語化を強制されると感動が味気なくなる本文の二つの要素がそろう → 正解

答え：エ
今回：エ ○（5点）。よく取れている。イは「感動の累積が心をつくる」という筆者の主張そのものを含んでいて、大人でも引かれる選択肢である。まん中まで読んで切るができていた。

一 問五 「モラルに衣服を着せてしゃべらせているだけのような作品」 ──線部の説明・記述12点

👀 まず見るところ

問いの最後は「どのようなものか」。文末は「〜作品。」と先に決めて、解答らんの終わりに書いてしまおう。次に傍線を切る。「モラルに／衣服を着せて／しゃべらせているだけの／ような作品」。四つともたとえである。つまりこれは、たとえを一つずつふつうの言葉に置きかえる問題だと、読んだ時点で決まる。たとえを残したままの答案は「説明していない」と見なされて点にならない。

📚 前提知識

  • 塾技77「──線部の説明」：比喩は意味がぶれないように別の言葉に言いかえ、指示語は本文を読んでいない人にも分かるように書き直す。
  • 塾技29「比喩表現」：何を何にたとえたのかを分ける。ここは〈中身＝モラル〉に〈外側＝衣服〉を着せている、という形。中身が先にあって、外側はあとから着せられている、という順番がこのたとえの命である。
  • 本文のモラルの中身：「時代の影響を受け」「新しい道義、新しい教訓の材料」。上からのせたモラルについては「意識の表面だけをすくいとった陳腐なもの」とある。

✍️ 答案の組み立て

12点なので部品は3〜4個。傍線を切った三つが、そのまま三つの部品になる。

  1. 部品A（モラル＝中身）：本文の「時代の影響を受け」「新しい教訓の材料」から →「時代の状況に合わせて選んだ道義や教訓」。
  2. 部品B（衣服を着せてしゃべらせている＝どうしたか）：モラルが先にあって、物語はあとから着せた外側だ、という順番を言葉にする →「ストーリーを後から付けて物語の形に仕立てた」。
  3. 部品C（「だけの」「〜ような」＝筆者の評価）：この二語は見下した言い方なので、否定の評価語で締めくくる →「形式的な／表面的な／感動のない」。ここを落とすと、ただの作品の説明になってしまう。
  4. 文末を「〜作品。」で閉じる。

迷いやすいのは部品Bである。「しゃべらせている」を「登場人物にセリフを言わせる」と取ると、たとえを半分しか開けていないことになる。「衣服を着せて」と「しゃべらせて」はひとまとまりで、モラルに物語という服を着せて人間のふりをさせている、という一つの意味を作っている。ここは「衣服」のほうから訳すとうまくいく。

模範解答：時代の状況に合わせて見つくろった道義や教訓に、ストーリーを後付けして物語の体裁に仕立て上げた形式的な作品。
今回：12点中5点。答案は「歴然と時代の影響を受け、新しい教訓の材料として正邪の分かりきったものを登場人物として出した物語。」。
部品A ○。「時代の影響を受け」「新しい教訓の材料」は模範の「時代の状況に合わせて見つくろった道義や教訓」とほぼ同じで、ここは本文からよく取れている。
部品B ×。「登場人物として出した」だけでは、モラルが先で物語があとから着せられたという順番が出ていない。たとえの「衣服」をどこにも訳していないのが原因である。
部品C ×。「〜物語。」で終わっていて、否定の評価語が無い。採点者の赤字も「形式的」の三字だけで、指摘されたのはまさにこの締めくくりである。
次に同じ形が出たら、傍線に「だけの」「〜ような」が付いているのを見つけた時点で、解答らんの終わりに「形式的な作品。」と先に書いてしまう。それだけで今回の失点の半分は戻る。なお書き出しの「歴然と」は問一の語をそのまま持ってきたもので、無くても意味は通る。

一 問六 「絵」とはどのようなものか ──線部の説明・記号選択

👀 まず見るところ

この文章には絵が一枚も出てこないのに、「絵」という言葉が何度も出てくる。この時点でたとえだと決めてよい。傍線③のまわりから「絵」を集めると、「絵の書けない作者」「絵のうまい下手」「絵には力がこもっていない」。絵を書くのは作者なのだから、絵＝作者が書くもの＝物語（作品）だと決まる。

📚 前提知識

  • 塾技29「比喩表現」：同じたとえが何度も出てくるときは、出てくる場所を全部集めると意味が決まる。一か所だけで決めない。
  • 塾技51「言い換えの選択肢」：正解は本文の言葉をそのまま使わず、言いかえて作られている。「絵」という字が入っている選択肢が正解とはかぎらない。
  • 傍線の直後にある理由：その絵の中のモラルは、生涯のうちにのばした「精神的な根」から出ている。少しあとには「価値をもち得る唯一のモラルは、作者そのひと独特の全人格から必然的に生まれてくるものだけ」とある。絵は作者の内側から生まれる、が筆者の言い分である。

🔍 こう読み解く

  1. まず「絵＝物語（作品）」と決める。これで、絵を文字どおり挿絵と読んだアは切れる。
  2. 残りは「どこから生まれたものか」で比べる。本文は「精神的な根」「全人格から必然的に生まれてくる」。これに正面から合うのはウ「作者の内面から生まれた世界を形にした物語」である。
  3. 残りを切る。
選択肢切り方
ア 物語とそれを彩る挿絵「絵」をたとえと読めていない（本文外）
イ 読者の脳裏に描かれた画像本文は「絵のうまい下手」「絵には力がこもっていない」と、絵を作者が作った物として扱っている。読者の頭の中の話ではない（本文外）
ウ 作者の内面から生まれた世界を形にした物語「精神的な根」「全人格から生まれる」と合う → 正解
エ 歩んできた人生を具現化した作品本文が言うのは、モラルが生涯のうちに育った根から出るということ。作品が人生そのものの形だとまでは言っていない（言いすぎ）
オ 物語からにじみ出てくる人格それは絵から出てくるモラルのほうで、絵そのものの説明になっていない（問いに答えていない）
答え：ウ
今回：ウ ○（5点）。「絵」がたとえだと見ぬき、しかも「絵」という字の入っていない選択肢を選べている。記号選択で一番大事なところができている。

一 問七 「ひとりで読むことだけが個性を守るとりで」 ──線部の説明・記号選択

👀 まず見るところ

傍線④を切ると「ひとりで読むことだけが／個性を守る／とりで」。「とりで」は最後に立てこもって守る場所で、まわりは敵だらけという前提のあるたとえである。だから聞かれているのは「その敵とは何か」、つまり筆者がここまで批判してきた現状である。ここまで来れば、選択肢の前半にその現状が並んでいるかを見るだけでよい。

📚 前提知識

  • 筆者の批判は三つ。①感想を強要する読書指導（問四）②モラルを上からのせる作家（問五）③モラルだけをすくいとる批評家。
  • 「個性」＝「感動の累積が、わたしたちの心をつくっていく」（八行目）でできる、その人だけの心。ここを押さえると、なぜ「ひとりで」なのかが分かる。いっせいに同じ本の同じ感想を出させられる場では、自分だけの感動が積もらないからである。
  • 塾技55「誤り選択肢のパターン① 言いすぎ・本文に書かれていない」、塾技57「誤り選択肢のパターン③ 問題にきちんと答えていない」。

🔍 こう読み解く

  1. 「だけが」「とりで」を、ふつうの言葉で「〜でしか…できない」と言いかえた選択肢を探す。エの終わりが「ひとりで本を読むことでしか、感動を味わい独自の精神世界を築くことができない」で、そのまま重なる。
  2. エの前半も確かめる。「モラルを声高に叫ぶ作家」＝②、「モラルにしか興味をもたない批評家」＝③、「それを助長する読書指導」＝①。三つとも本文にあるので、エで決まる。
  3. 残りは、前半が本文と合っていても後半でくずれる。ここが今回のかん所である。
選択肢切り方
ア モラルを押し出した本ばかりが書店に並ぶ／子ども自身が見つけなければならない前半は本文と合うが、「書店に並ぶ」「子ども自身が見つける」は本文に無い（本文外）
イ 精神的にも経済的にも豊かになるお金の話は本文に一度も出てこない（本文外）
ウ 学校と親が協力して本を与えるしかない「ひとりで読む」から離れてしまっている（問いに答えていない）
エ ひとりで読むことでしか独自の精神世界を築けない批判してきた三つがそろい、「だけが」も訳せている → 正解
オ 優れた作家を評価するシステムが必要筆者はモラルで作品を評価する批評そのものを批判している。向きが逆（本文外）
答え：エ
今回：ア ×（5点）。アの前半「モラルを前面に押し出した本ばかり」は本文と合っているので、そこで決めてしまったのだと思う。長い選択肢は前半で決めず、後半までそろえて読む。今回なら「書店」という言葉が本文に一度も出てこないと気づいた時点で切れた。選択肢に出てきた言葉を、本文の中で指でさがすのが一番速い確かめ方である。

山田詠美「埋葬のしあげ」（『色彩の息子』所収・新潮社）

裕福な家の末っ子「ぼく」（信介）が語る物語。二人の兄と姉たちはあらゆる点で秀でていて、「ぼくを抜かした家族の連中は、優越感という絆で結びついていた」。ぼくだけがその外側にいて、父からは留学＝家からの追い出しを提案され、自分に対する嫌悪にくるまれて眠る。

二 問二AB 空らんA・Bに入る言葉 慣用句の空欄補充・字数指定

👀 まず見るところ

空らんの前後のことば。A は「ぼくの意志など、□□に足りないことなのだ」、B は「ぼくは□にもなく話し過ぎた」。どちらも空らんを含めてひとつの慣用句になる形である。「A はひらがな二字、B は漢字一字」という指定も、慣用句を思い出すための手がかりとして使おう。

📚 前提知識

  • 塾技98「ことわざ・慣用句」。取るに足りない＝わざわざ取り上げるほどの値打ちもない。（例）そんな取るに足りないうわさを気にすることはない。
  • 柄にもない＝その人らしくない、ふだんの自分に似合わない。（例）柄にもなく緊張してしまった。
  • 塾技70「キーワードの空欄補充問題」。空らんは、前後のことばとセットにして初めて意味が決まる。

🔍 こう読み解く

  1. A：直前が「ぼくの意志など」、直後が「〜に足りない」。留学も何もかも先に決められていて、自分の意志には値打ちがない、という流れ。慣用句は「取るに足りない」で、ひらがな二字ならとる。
  2. B：ふだんは家族ともほとんど口をきかない「ぼく」が、恵子には家のことまで話してしまった場面。自分らしくないほど話した、という流れで「柄にもなく」。漢字一字なので柄。
  3. 入れたら、空らんごと1文を読み返す。これで「日本語になっているか」を自分で確かめられる。
答え：A とる　B 柄
今回：A「さじ」×／B「間」×。0点。A の「さじを投げる（あきらめる）」も B の「間」も、ことば自体は思い浮かんでいる。ただ「さじに足りない」「間にもなく」と入れて読み返すと日本語にならない。入れたあとに前後ごと読み直す、これだけで6点が戻る。

二 問八 「彼女の言葉を反芻し続ける」ときの様子 記号選択・場面の様子

👀 まず見るところ

⑥を含む一文「ぼくは、呆然として、彼女の言葉を反芻し続けるだけだった」。この「呆然として」と「だけだった」が、そのまま今のぼくの様子である。物語の最後は「このあと立ち直る」ところまで書いた選択肢が必ず混ざるので、反芻より先へ進んだものは切ると決めてから読もう。

📚 前提知識

  • 反芻＝牛などが一度飲みこんだ食べ物を口にもどしてかみ直すこと。そこから転じて「繰り返し考え、よく味わう」。ここは後の意味。
  • 塾技55「誤り選択肢のパターン① 言いすぎ・本文に書かれていない」。
  • 塾技50「本文と選択肢の照合」。長い選択肢は前半（それまでの状況）と後半（今の様子）に分けて照らす。

🔍 こう読み解く

  1. 後半の判定基準を2つ決める。呆然としている／意味を考えている。
  2. ア「人生についての考え方を修正しようとしている」、イ「自分の価値観を確立しようとしている」、ウ「自暴自棄になっていた自分と訣別しようとしている」は、どれも反芻より先へ進んでいる。
  3. エ「初めて人との絆を感じる」。本文の「絆」はぼくを抜かした家族が優越感で結ばれているもので、恵子との間に絆を感じたとは書かれていない。
  4. 残ったオは、前半が「一人だけなんの才能にも恵まれぬ」「疎外感と自己嫌悪」で本文どおり、後半も「とまどいつつも…意味を考えながら心に刻んでいる」で、呆然と反芻に重なる。
答え：オ
今回：オ ○。この大問でいちばん長い選択肢だが、後半だけを先に見比べて決められている。よい解き方である。

二 問三 「厚い毒の層のようなもの」とはどのようなものか 記述12点・比喩の説明

👀 まず見るところ

問いの最後は「どのようなものか。説明しなさい」なので、文末は「〜もの。」でよい。傍線は「厚い／毒の層の／ようなもの」と切れる比喩で、それを張り巡らせているのは直前の「彼ら」＝二人の兄と姉たち。つまり兄と姉が出しているものの中身を、本文のことばに置きかえる問題だと決まる。12点なので部品は3〜4個、と先に決めておく。

📚 前提知識

  • 塾技77「──線部の説明」。比喩は別のことばに言いかえ、指示語は本文を読んでいない人にも伝わるように書き直す。
  • 塾技29「比喩表現」。「毒」は否定的なもの、「層」は厚みをもってぼくを取り囲んでいるもの。二語とも別々に言いかえる。
  • 塾技12「指示語の活用」。「彼ら」が誰かを先に確かめてから書き始める。
  • 語句：疎外感＝仲間に入れてもらえない感じ。連帯感＝仲間どうしで結びついている感じ。

✍️ 答案の組み立て

  1. 部品A（ぼくの側）：「ぼくは兄や姉どころか、まわりの人々よりも、あらゆる点で劣り」→「優秀な家族の中で一人だけあらゆる点で劣っている」。
  2. 部品B（ぼくの側・もう1つ）：同じ一文の続き「そのことを気に病んで、人と打ちとけることの出来ない人間だったのだ」→「人と打ちとけることもできない」。一文の後半にあるので落としやすい部品である。
  3. 部品C（毒＝兄姉からぼくへ）：「兄や姉は、くすくすと笑い、時には、はっきりと嫌悪の言葉を口にした」→ ぼくに対する「嫌悪」。
  4. 部品D（層＝兄姉どうし）：「ぼくを抜かした家族の連中は、優越感という絆で結びついていた」→ 自分たちの優位性を兄と姉で共有する「連帯感」。これがぼくを取り囲む「層」の厚みにあたる。
  5. C と D を「〜に対する嫌悪と、〜連帯感。」と並べ、その前に A と B を付けて、ぼくがどんな存在かを説明する。

迷いやすいところ：「毒の層」を「ぼくを息苦しくさせる空気」とだけ言いかえて終わりにしがちである。模範解答は嫌悪と連帯感という2つの気持ちの名前で答えている。比喩の説明は、ふんいきではなく気持ちの名前まで下ろすと点になる。

模範解答：優秀な家族の中で一人あらゆる点で標準より劣り、人と打ちとけることもできない「ぼく」に対する嫌悪と、自分たちの優位性を、兄と姉とで共有する連帯感。
今回：12点中4点。答案は「自分は小さいころから強みがなく、劣っていたのに、兄たちは、自分のとなりで家族とも優越感にひたっていたので、優しゅうな兄と自分の差から感じる圧のようなもの。」。
部品A ○（劣っている）／部品B ×（打ちとけられない、が無い）／部品C ×（嫌悪が無い）／部品D 半分（「優越感にひたっていた」までは書けているが、兄と姉で共有している連帯感という形になっていない）。
先生は答案の「優越感」から下へ赤線を引いて「きずな」と書き、余白には「うちとける／出来る ×」と書いている。どちらも本文にそのまま書いてあることばなので、本文にもどれば取れた部品である。次は、比喩の中に「ぼく」と「兄や姉」の両方が出てきたら、片方ずつ本文に線を引いてから書き始めよう。

二 問七 恵子が言おうとしていること 記述12点・セリフの意図と対比

👀 まず見るところ

問いの最後は「どのようなことを言おうとしているのか」。セリフの裏の意味を答える問題なので、文末は「〜ということ。」。そして傍線は「お兄様がたより、あなたの方が、ずっと、小説の題材を抱えてる人間だわ」——ここに「より／の方が」がある。この時点で、兄たちの側とぼくの側の両方が部品になると決まる。書き出す前に、解答らんを心の中で2つに割っておこう。12点なので部品は3〜4個。

📚 前提知識

  • 塾技80「『対比』の記述」。「AよりBの方が」は、AとBの両方を書いて初めて答えになる。片側だけでは半分も点が来ない。
  • 塾技84「記述の注意点② セリフの扱い」。セリフはそのまま写さず、言いたい中身に直す。「小説の題材を抱えてる人間」は恵子独特の言い方なので、ふつうのことばに置きかえる。
  • 塾技9「『対比』の発見」。恵子自身が直後に「私から見たら、信介さんの方が、ずっと価値ある人間ということです」と言いかえてくれている。これが答えの向きを決める手がかりになる。

✍️ 答案の組み立て

  1. 部品A（兄たちの側）：「自分の優秀さを鼻にかけ、人を蔑み心無い言動をとる」。この部品は傍線のまわりには無く、文章の冒頭から取る——「兄や姉は、くすくすと笑い、時には、はっきりと嫌悪の言葉を口にした」、ぼく自身の「あの人たちが、自分たちの優れてることを知り尽くしてるせいさ」「ぼくを蔑むのも当然かもしれない」。
  2. 部品B（ぼくの側）：「ぼく、この家に合わないんだから」「ぼくも、いつも才能ないって馬鹿にされてる」「死んでも、多分、誰も悲しまないと思うな」→「劣等感や疎外感にさいなまれている」。
  3. 部品C（ぼくの側・もう1つ）：その苦しさを恵子の前で口に出したこと自体→「心の痛みを口にする」。恵子はこの話を聞いた直後に呼び止めているので、ここが評価の理由になっている。
  4. 部品D（言いかえ＝結論）：「小説の題材を抱えてる人間」＝書くに値する中身を持っている＝「人間味があって魅力的」。直後の「価値ある人間」と合わせて、「〜ということ。」で閉じる。

迷いやすいところ：ぼくの側だけを「かわいそうな人」「がんばっている人」とまとめると、兄たちの側が空いたままになる。傍線に「より」を見つけた時点で、「兄や姉は〜、ぼくは〜」と2つ並べてメモしてから文にすると、この失点は起きない。

模範解答：自分の優秀さを鼻にかけ、人を蔑み心無い言動をとる兄や姉よりも、劣等感や疎外感にさいなまれ、心の痛みを口にする「ぼく」の方が、人間味があって魅力的であるということ。

部品A ×（兄や姉の側がまったく無い）／部品B ×（劣等感・疎外感という中身が無い）／部品C 半分（「色々なことを考え話してくれて」で、話したことには触れている）／部品D 半分（「素晴らしい人」で価値の高さは言えている）。先生も余白に赤で「疎外感」と書いて丸で囲んでいる。
